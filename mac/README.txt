SmartScreen for Mac - 설치 안내
=====================================================================

자리를 비우면 Mac 화면을 가리고, 돌아오면 푸는 프로그램입니다.
거리는 아이폰의 블루투스 신호 세기(RSSI, dBm)로 판단합니다.
Windows 판 SmartScreen 과 같은 프로그램이고, 같은 아이폰 앱(SSBeacon),
같은 구글 계정, 같은 서버를 씁니다. Windows PC 와 Mac 을 섞어 써도 됩니다.

같은 구글 계정으로 로그인한 PC/Mac 끼리 클립보드를 주고받는 기능도
있습니다 (6장). 그 기능은 폰도 블루투스도 쓰지 않고, 기본으로 꺼져 있습니다.

새 버전이 나오면 프로그램이 스스로 알아채서 알려 주고, 확인하면 받아서
다시 시작합니다 (10장).


1. 준비물
---------------------------------------------------------------------
- macOS 13 (Ventura) 이상 Mac. Apple Silicon, Intel 모두 됩니다.
- 블루투스 (Mac 에 내장돼 있습니다)
- 아이폰 + 컴패니언 앱 SSBeacon

※ 아이폰은 잠기면 블루투스 신호를 스스로 멈춥니다.
   컴패니언 앱이 대신 신호를 계속 내보내므로, 앱이 있어야 제대로 동작합니다.


2. 설치 순서
---------------------------------------------------------------------
(1) zip 을 풀면 나오는 SmartScreen.app 을 "응용 프로그램" 폴더로 옮깁니다.

    ※ 다운로드 폴더에 둔 채로 실행하지 마세요. macOS 가 그 자리의 앱을
      읽기 전용 임시 위치로 옮겨 실행하기 때문에 자동 업데이트가 되지
      않습니다 (10장).

(2) 처음 한 번은 macOS 가 막습니다.
    이 앱은 Apple 개발자 인증서로 서명되지 않았기 때문입니다.
    "터미널" 앱을 열고 아래 한 줄을 붙여넣은 뒤 Return 을 누르세요.

      xattr -dr com.apple.quarantine /Applications/SmartScreen.app

    그다음 응용 프로그램 폴더에서 SmartScreen 을 더블클릭합니다.

    터미널을 쓰기 싫으면: 한 번 더블클릭해서 막히게 한 뒤
    시스템 설정 > 개인정보 보호 및 보안 > 아래쪽 "SmartScreen" 옆
    [그래도 열기] 를 누르고, 다시 더블클릭합니다.

(3) 블루투스 허용에 대해 미리 알아 둘 것.
    처음으로 보호를 켤 때(아래 (7)) 또는 "블루투스로 직접 등록" 을 할 때
    "SmartScreen 이(가) 블루투스를 사용하려고 합니다" 창이 뜹니다. [허용] 을 누르세요.
    거절하면 폰을 알아볼 수 없고, 프로그램이 "블루투스 권한이 없어요" 라고 알려 줍니다.
    그때는 시스템 설정 > 개인정보 보호 및 보안 > 블루투스 에서 SmartScreen 을 켜세요.

(4) 아이폰에 SSBeacon 앱을 설치하고 실행합니다.
    화면의 "광고" 원이 초록색이면 준비된 것입니다.
    ("연결" 원은 회색이어도 정상입니다. 3장 참고)
    블루투스 페어링은 하지 않아도 됩니다.

(5) 간단한 설정 창이 열립니다. 여기서 필요한 설정은 다 됩니다.
    dBm 이나 이벤트 기록 같은 것은 오른쪽 위 [고급 설정] 안에 있습니다.

    ※ 이 프로그램은 Dock 에 아이콘이 없고 메뉴 막대도 없습니다.
      창을 닫아도 프로그램은 계속 돕니다.
      화면 오른쪽 위에 떠 있는 작은 상자의 [설정] 을 누르면 다시 열립니다.
      응용 프로그램 폴더(또는 Launchpad)에서 SmartScreen 을 다시 열어도
      설정 창이 나옵니다.

(6) "내 폰" 줄의 [등록하기] 를 누릅니다.  ★ 꼭 필요합니다

    아이폰은 잠기면 이름 없이 계속 바뀌는 주소로만 신호를 보냅니다.
    그래서 "이 폰이 내 폰" 임을 알려주는 값을 한 번 정해 둡니다.

    누르면 두 가지 중에 고르라고 물어봅니다.

    [예] 구글 계정으로 등록                      ← 권장
      (1) 먼저 아이폰 SSBeacon 앱에서 "구글 계정으로 연결" 을 눌러
          구글 로그인을 합니다. "연동되었습니다" 가 뜨면 됩니다.
      (2) 그다음 Mac 에서 [등록하기] → [예] 를 누르고
          같은 계정으로 로그인합니다. 브라우저가 열립니다.
          로그인이 끝나면 브라우저 탭을 닫고 돌아오면 됩니다.
          결과 창이 안 보이면 화면 오른쪽 위 작은 상자의 [설정] 을 누르세요.

      - 폰을 Mac 가까이 둘 필요도, 앱을 띄울 필요도 없습니다.
      - Windows PC 에서 이미 같은 계정으로 등록했다면 Mac 에서도
        로그인만 하면 같은 폰을 알아봅니다.
      - 순서가 중요합니다. 폰에서 먼저 로그인해야 Mac 이 가져올 값이
        생깁니다. 폰보다 먼저 누르면 "등록된 폰이 없습니다" 가 뜨는데,
        고장이 아니라 아직 폰 차례라는 뜻입니다.

    [아니오] 블루투스로 직접 등록                ← 인터넷이 없을 때
      - 아이폰에서 SSBeacon 앱을 화면에 띄운 채로 두고 누릅니다.
      - 폰을 Mac 가까이 두세요.
      - 잠긴 상태로는 등록되지 않습니다. 옆자리 폰을 잘못 잡을 수
        있어서 일부러 막아 두었습니다.

    어느 쪽이든 "폰을 등록했습니다" 와 함께 8자리 값이 뜹니다.
    앱 화면 아래의 "기기 토큰" 과 같은 값인지 확인하세요.

(7) [보호 꺼짐] 을 눌러 켭니다 ([보호 켜짐] 으로 바뀝니다).
    등록된 폰이 있으면 다음부터는 켤 때 저절로 시작합니다.

(8) [내 자리에 맞게 재보기] 로 거리를 맞춥니다 (4장).

(9) 아이폰을 주머니에 넣고 자리를 떠 보세요.
    10~20초 안에 화면이 가려지면 정상입니다.
    돌아오면 저절로 풀리고, 마우스나 키보드를 써도 바로 풀립니다.

    ※ 저절로 풀리는 것은 Mac 이 깨어 있고 화면이 켜져 있는 동안뿐입니다.
      맥북을 배터리로 쓰면 macOS 가 2분쯤 뒤(전원을 꽂으면 10분쯤 뒤)
      화면을 끄고 잠자기에 들어갑니다. 그 뒤에 돌아오면 아무 키나 눌러
      깨운 다음 Touch ID 나 암호로 여세요. 고장이 아니라 정상입니다.

(10) 로그인할 때 저절로 켜지게 하려면:
     시스템 설정 > 일반 > 로그인 항목 > "로그인 시 열기" 의 [+] 에서
     응용 프로그램 폴더의 SmartScreen 을 추가합니다.


3. 두 가지 감지 경로
---------------------------------------------------------------------
프로그램이 알아서 고릅니다. 사용자가 설정할 것은 없습니다.

  [광고]  앱이 신호를 내보내고 Mac 이 받습니다. 갱신 1~6초.
          고급 설정 창 아래에 GATT: off 또는 waiting 으로 표시됩니다.

  [연결]  Mac 과 앱이 연결을 유지합니다. 갱신 1초로 더 빠릅니다.
          되는 경우 고급 설정 창 아래에 GATT: linked 로 표시됩니다.

둘 다 실사용에 충분합니다.

※ 아이폰 앱은 가장 먼저 찾은 PC/Mac 하나에만 [연결] 로 붙습니다.
  Windows PC 와 Mac 이 둘 다 켜져 있으면 한쪽은 [광고] 경로로 동작하는데,
  정상입니다.


4. 얼마나 멀어지면 가릴지 정하는 법  (가장 중요)
---------------------------------------------------------------------
자리와 기기마다 신호 세기가 다릅니다. 같은 "보통" 이 자리에 따라
10~20dB 씩 달라지기 때문에, 한 번은 재야 합니다.
Windows PC 에서 잰 값을 Mac 에 그대로 쓰지 마세요. 안테나가 다릅니다.

  창에서 [내 자리에 맞게 재보기] 를 누르면 2분쯤 걸려 끝납니다.

    1. 폰을 평소 두는 자리에 두고 1분 동안 앉아 있기
    2. 폰만 "화면이 꺼지길 원하는 곳" 에 두고 오기
    3. 자리에 앉아서 45초 기다리기

  끝나면 앉아 있을 때와 비웠을 때의 값을 보여주고 "보통" 을
  이 자리에 맞게 맞춰 줍니다. 더 빨리/늦게 가리게 하고 싶으면
  그 위의 막대를 "가까이" 나 "멀리" 로 옮기면 됩니다.

  재는 도중에는 화면이 가려지지 않습니다.

  ※ 이럴 때는 값을 쓰지 않고 이유를 알려줍니다.
     - 신호를 거의 못 받았다       -> 폰 앱이 켜져 있는지, 블루투스 권한을
                                      허용했는지 보세요 (2-(3))
     - 앉을 때와 비울 때가 겹친다  -> 폰을 더 멀리 두고 다시 하세요

  앉아 있는데 가려진다       -> 막대를 "멀리" 쪽으로 (또는 신호 강도 숫자를 낮춤)
  자리를 떠도 안 가려진다    -> 막대를 "가까이" 쪽으로 (또는 숫자를 높임)

  ■ 손으로 재는 방법 — 확인하거나 더 정확히 하고 싶을 때

  Windows 판 설명서 4장의 방법이 그대로 됩니다. 두 번은 재야 합니다 (한 번만 재면
  앉아 있을 때의 가장 약한 값을 놓칩니다).

  (1) 프로그램을 종료하고 (7장) 설정 파일의 bleDebugLog 를 1 로 바꾼 뒤 다시 켭니다.
  (2) 고급 설정의 "신호 강도" 를 -90 으로 넣고 [시작] (재는 동안 가려지지 않게).
      맥북이면 전원을 꽂거나, "터미널" 에서 아래 한 줄을 실행해 둡니다.
        caffeinate -di
      배터리로 쓰는 맥북은 손을 대지 않으면 2분쯤 뒤 화면을 끄고 잠들어서
      그동안의 기록이 비게 됩니다. 다 재고 나면 그 터미널에서 Control-C 로 멈춥니다.
  (3) 폰을 평소 두는 자리에 두고 2분 앉아 있기 → 원하는 지점에 2분 → 돌아와 1분.
      각 구간의 시각을 적어 둡니다. 이것을 두 번.
  (4) ~/Library/Application Support/SmartScreen/ble_scan_log.csv 가 기록입니다.
      6번째 열(matched)이 1 인 줄의 8번째 열(smoothedRssi)을 구간별로 봅니다.
      Windows PC 가 있으면 그 폴더를 복사해 가서 rssi-threshold.ps1 이 계산하게 할 수
      있습니다 (명령 끝에 -LogDir "<복사한 폴더>" 를 붙입니다).
  (5) 앉아 있을 때의 "가장 약한" 값과 나갔을 때의 "가장 센" 값 사이에 임계값을 넣고,
      bleDebugLog 를 0 으로 되돌립니다 (파일이 계속 커집니다).


5. 함께 들어 있는 점검 도구
---------------------------------------------------------------------
Windows 판의 ProbeScan.exe / AdvScan.exe / BtCheck.exe 가 Mac 에서는
앱 안에 들어 있습니다. "터미널" 에서 실행합니다.

  잠긴 폰에서 신원을 읽어 오는지 (폰을 잠근 채로):
    /Applications/SmartScreen.app/Contents/MacOS/SmartScreen --probe-scan

    SmartScreen 이 켜져 있으면 오른쪽 위 작은 상자의 [종료] 로 끈 뒤에 하면
    결과가 깨끗합니다. 1분쯤 세 단계로 폰을 찾습니다:
      1 필터 스캔      macOS 에 "SmartScreen 신원 서비스" 로 걸러 달라고 한다
      2 직접 읽기 스캔  거르지 않고 Apple 광고의 제조사 데이터를 직접 읽는다
      3 둘 다 동시에    프로그램이 실제로 도는 모양
    그다음 찾은 기기에 붙어 신원을 읽고 (">>> 토큰" 줄), 맨 끝에
    "요약" 블록을 찍습니다. 문제를 알릴 때는 그 블록을 그대로 보내 주세요.
    요약의 "결과:" 줄이 어느 길로 잠긴 폰을 찾는지 말합니다:
      필터 경로 / 직접 읽기 경로 / 둘 다   -> 정상
      판정 못 함    -> 아무것도 결론 내지 말고 1~2분 뒤 같은 명령을 다시
                       실행하세요. 폰을 봤지만 연결이 안 됐거나(흔합니다),
                       내 폰인지 토큰으로 확인하지 못한 것입니다. 그 줄 아래의
                       설명대로 하세요 (예: 등록된 토큰과 다르면 [등록하기] 를 다시)
      둘 다 안 됨   -> 어느 스캔도 폰을 보지 못했습니다. 폰 앱의 "광고" 원이
                       초록색이었다면 광고로는 못 찾는 Mac 입니다. 보호를 켠 뒤
                       고급 설정 창 아래의 GATT 줄이 linked 가 되는지 보세요
      "시험하지 못함" / "시험하지 못했습니다" 가 들어 있으면 다시 실행하세요
    "주의:" 줄이 있으면 그 말대로 다시 해 보세요 (예: 폰을 잠그지 않았다).

  다른 PC/Mac 의 SmartScreen 신호가 들리는지:
    /Applications/SmartScreen.app/Contents/MacOS/SmartScreen --adv-scan

  이 Mac 의 블루투스 상태:
    /Applications/SmartScreen.app/Contents/MacOS/SmartScreen --bt-check

  ※ 터미널에서 처음 실행하면 "터미널" 이 블루투스를 쓰려 한다는 창이
    뜹니다. [허용] 을 누르세요. 터미널에서 실행하면 macOS 는 블루투스
    권한을 SmartScreen 이 아니라 터미널에 묻습니다. 도구는 창에 답할 때까지
    60초를 기다립니다.
    - [허용] 을 누르기 전에 도구가 끝났으면 ("허용 창에 답하지 않았습니다")
      [허용] 을 누른 뒤 같은 명령을 다시 실행하세요.
    - [허용 안 함] 을 눌렀으면 ("블루투스 권한이 없습니다")
      시스템 설정 > 개인정보 보호 및 보안 > 블루투스 에서 "터미널" 을 켜고
      다시 실행하세요. 그 목록의 SmartScreen 이 아니라 "터미널" 입니다.
      (iTerm, Visual Studio Code, Cursor 같은 다른 앱에서 실행했다면 그 앱을
      켭니다. 도구가 그 앱의 이름을 알려 줍니다)


6. 다른 PC/Mac 와 클립보드 공유
---------------------------------------------------------------------
같은 구글 계정으로 로그인한 PC/Mac 사이에서 복사한 것을 주고받습니다.
Windows PC 에서 캡처하면 Mac 에서 Command+V 로 붙고, 반대도 됩니다.

  · 같은 네트워크일 필요가 없습니다
  · 폰도 블루투스도 필요 없습니다
  · 넘어가는 것은 글과 그림뿐입니다. 파일은 넘어가지 않습니다

  켜는 순서
  (1) 양쪽 모두 [내 폰] 의 [등록하기] 에서 "구글 계정으로 등록" 을 고르고
      같은 계정으로 로그인합니다 (폰 등록을 겸합니다)
  (2) 양쪽 모두 창 아래 [클립보드 공유 꺼짐] 을 눌러 켭니다
  (3) Mac 에서 Command+Control+Shift+4 로 화면 일부를 클립보드에 캡처하고,
      다른 PC 에서 Ctrl+V. 최대 5초 걸립니다

  ※ 복사한 내용이 서버를 지나갑니다.
    화면 사진, 코드, 붙여넣으려던 비밀번호가 모두 같은 통로로 갑니다.
    본인 계정으로 로그인한 사람만 볼 수 있지만, 필요할 때만 켜 두세요.
    암호 관리자(1Password 등)가 "기록하지 말라" 고 표시해 둔 것은 보내지 않습니다.
    표시를 달지 않는 앱에서 복사한 암호는 넘어갑니다.
    아이폰·아이패드에서 복사해 Mac 에 넘어온 것(유니버설 클립보드)은 다른 PC 로
    보내지 않습니다. Mac 에서 Command+V 로 붙는 것은 그대로입니다.

  잘 안 될 때
  타일 아래 한 줄이 마지막 결과를 말해 줍니다. 그것을 먼저 보세요.

    "계정으로 로그인하면 쓸 수 있어요"  -> (1) 을 먼저 하세요.
    "안 됨: ... [401] ..."               -> 로그인이 풀렸습니다. 다시 로그인하세요.
    "안 됨: ... [403] ..." 또는 "[404]"  -> 서버 쪽 준비가 안 된 상태입니다. 아래 점검을 돌려 보세요.
    "... KB 라 건너뜀"                   -> 그림이 너무 큽니다. 화면 전체 대신 일부만 캡처해 보세요.
    "macOS 설정에서 이 앱의 클립보드 읽기가 막혀 있어요"
                                         -> 이 Mac 이 다른 앱의 클립보드를 읽기 전에 묻도록 설정돼
                                            있으면, 시스템 설정 > 개인정보 보호 및 보안 >
                                            다른 앱에서 붙여넣기 에서 SmartScreen 을 "허용" 으로
                                            바꾸세요.

  점검 (터미널에서):
    /Applications/SmartScreen.app/Contents/MacOS/SmartScreen --clip-test
  올리기 / 조회 / 내려받기 / 덮어쓰기를 이 Mac 한 대에서 차례로 해 보고
  어디서 막히는지 알려줍니다. 결과는
  ~/Library/Application Support/SmartScreen/clip-test.txt 에도 적힙니다.

  ※ SmartScreen 을 먼저 끄세요 (오른쪽 위 작은 상자의 [종료]).
    점검이 로그인을 새로 받아 설정 파일에 저장하는데, 켜져 있는 SmartScreen 도
    같은 파일에 로그인 정보를 씁니다. 둘이 겹치면 로그인이 풀릴 수 있어서,
    켜져 있으면 점검이 그렇게 말하고 멈춥니다.


7. 설정 파일
---------------------------------------------------------------------
~/Library/Application Support/SmartScreen/config.ini

Finder 에서 Command+Shift+G 를 누르고 위 경로를 붙여넣으면 열립니다.
Windows 판과 같은 이름과 같은 뜻입니다.

프로그램을 완전히 종료한 뒤 (오른쪽 위 작은 상자의 [종료]) 텍스트 편집기로
편집하세요. 켜 둔 채로 고치면 프로그램이 덮어씁니다.

  nearRssiThreshold   임계값 (dBm). 설정 창의 "신호 강도" 와 같은 값
  gattRssiThreshold   위와 같은 값의 사본입니다. [시작] 을 누르면 다시 맞춰집니다
  measuredBaseRssi    재보기가 정한 "보통" 의 기준. 0 이면 아직 안 재 봤습니다
  bleLostMeansFar     1이면 신호가 끊기는 것을 자리 비움으로 봅니다. 1 로 두세요
  bleDebugLog         1이면 신호를 전부 기록합니다 (4장). 평소에는 0
  bleTimeoutSec       이 시간 동안 신호가 없으면 끊긴 것으로 봅니다 (기본 90초)
  phoneToken          등록한 폰의 식별값. [등록하기] 가 채웁니다. 지우지 마세요
  phoneOvfBit         잠긴 폰을 빨리 찾으려고 프로그램이 스스로 배워 적는 번호
                      (-1 = 아직 모름). 손대지 않아도 됩니다
  clipSync            1이면 클립보드를 주고받습니다 (6장). 화면의 타일이 바꿉니다
  clipMaxKB           이보다 큰 것은 건너뜁니다 (기본 4096 = 4 MB, 최대 8192)
  updateCheck         1이면 새 버전이 있는지 서버에 묻습니다 (10장). 0이면 안 묻습니다
  updateChannel       stable 또는 beta. 평소에는 stable

  Mac 에서 쓰지 않는 값: bleIrk, btAddress (그대로 둡니다)


8. 문제 해결
---------------------------------------------------------------------
프로그램 창이 안 보인다
  -> 화면 오른쪽 위에 작은 상태창이 떠 있습니다. "설정" 을 누르세요.
  -> 응용 프로그램 폴더에서 SmartScreen 을 다시 열어도 됩니다.

자리를 떠도 안 가려진다 / 잠긴 폰을 못 알아본다
  -> [등록하기] 를 했는지 보세요. "내 폰" 줄이 "등록됨" 이어야 합니다.
  -> 블루투스 권한을 허용했는지 보세요 (2-(3)).
  -> 등록한 뒤 앱을 지웠다 다시 설치했다면 [등록하기] 를 다시 누르세요.
     (구글 계정으로 등록했다면 그럴 필요가 없습니다)
  -> 5장의 --probe-scan 을 폰을 잠근 채로 돌려 보세요.
     ">>> 토큰" 줄이 나오면 폰 쪽은 정상입니다.
  -> 아이폰에서 SSBeacon 의 "광고" 원이 초록색인지 확인하세요.
     앱을 위로 밀어 종료하면 신호가 멈춥니다. 홈으로 나가는 건 괜찮습니다.
  -> 4장으로 거리를 다시 맞추세요.

화면이 가려진 채 안 풀린다
  -> 마우스를 움직이거나 아무 키나 누르면 풀립니다.
     화면 오른쪽 위 [해제] 로도 풀 수 있습니다.

돌아왔는데 저절로 안 풀리고 Touch ID / 암호를 묻는다
  -> 정상입니다. 저절로 풀리는 것은 Mac 이 깨어 있고 화면이 켜져 있는
     동안뿐입니다. 맥북을 배터리로 쓰면 macOS 가 2분쯤 뒤(전원을 꽂으면
     10분쯤 뒤) 화면을 끄고 잠자기에 들어가고, 그동안은 이 프로그램도 멈춰
     있습니다. 아무 키나 눌러 깨운 다음 Touch ID 나 암호로 여세요.
  -> 기록(events.log)에 그 시각의 "DISPLAY OFF", "SLEEP" 줄이 있으면
     그 경우입니다 (깨어나면 "WAKE", "DISPLAY ON").

잠금 화면에 동영상이 안 나온다
  -> Mac 은 mp4 / mov 만 재생합니다. avi, wmv, mkv, webm 은 재생하지 못하고
     그 자리에 그림이 없을 때의 어두운 상자가 보입니다.
     회사 대시보드에 mp4 로 올려 달라고 하세요.

아이폰 앱이 "이 PC는 광고 경로 사용" 이라고 뜬다
  -> 정상입니다. [광고] 경로로 잘 동작합니다 (3장).

기록 보기
  -> ~/Library/Application Support/SmartScreen/events.log


9. Windows 판과 다른 점
---------------------------------------------------------------------
- "기기 키" 는 Mac 에 없습니다. macOS 가 블루투스 주소와 키를 앱에 주지
  않기 때문입니다. [폰 등록] 만 쓰면 됩니다.
- 페어링된 기기(헤드폰 등)를 대상으로 고르는 예전 방식이 없습니다.
  등록한 폰만 대상입니다. 그래서 [재연결] 도 쓰이지 않습니다.
- 원격 접속으로 쓰는 중에는 가리지 않는 규칙은, macOS 에서는 "다른 사용자
  세션으로 접속해 있을 때" 만 알아챕니다. 화면 공유로 같은 세션을 보는
  경우는 Windows 에서 TeamViewer 를 못 알아채는 것과 같이 알아채지 못합니다.
- 잠금 화면 동영상은 mp4 / mov 만 재생합니다 (8장).
- 로그인 정보는 이 Mac 에만 묶어 저장합니다. 설정 파일을 다른 Mac 에
  복사하면 거기서는 다시 로그인해야 합니다 (Windows 판과 같습니다).
- 그림을 고르지 않았을 때의 기본 그림은 Windows 에서는 exe 옆의 images 폴더였습니다.
  Mac 에서는 ~/Library/Application Support/SmartScreen/images/center.png
  (배너는 banner.png. jpg, bmp 도 됩니다) 에 두면 됩니다.
- 컴패니언 앱을 무료 Apple 계정으로 서명했다면 7일마다 다시 설치해야 합니다.


10. 프로그램 업데이트
---------------------------------------------------------------------
프로그램은 켤 때와 한 시간마다 새 버전이 있는지 서버에 묻습니다.
설정 창 왼쪽 위에 "버전 x.y.z · 업데이트 확인" 이 있고, 누르면 바로 확인합니다.

새 버전이 있으면 창 아래에 띠가 뜹니다.
  [업데이트]  받아서 다시 시작합니다. 설정은 그대로입니다.
  [나중에]    이번에는 넘어갑니다. 더 새 버전이 나오면 다시 뜹니다.

기업용으로 등록된 Mac 은 묻지 않습니다. 회사 관리자가 대시보드에서
Mac 버전을 승인하면 스스로 바뀝니다. 승인 전에는 "관리자 승인을 기다려요"
라고만 보입니다.

화면을 가리는 중에는 다시 시작하지 않고, 풀린 뒤에 합니다.

예전 앱은 SmartScreen.app.bak 으로 잠깐 남았다가, 새 버전이 무사히 뜨면
지워집니다. 새 버전이 뜨지 않으면 SmartScreen.app 을 지우고 SmartScreen.app.bak 의
이름을 SmartScreen.app 으로 바꾸면 예전대로 쓸 수 있습니다.

업데이트가 안 된다
  -> 설정 창의 버전 단추를 눌러 보세요. 이유가 띠에 나옵니다.
  -> events.log 의 "update:" 줄에 자세한 이유가 남습니다.
  -> 다운로드 폴더에서 바로 실행 중이면 바꿀 수 없습니다. 응용 프로그램
     폴더로 옮긴 뒤 다시 켜세요.
  -> 한 번 실패한 버전은 저절로 다시 시도하지 않습니다. 띠의 [다시 시도] 를
     누르면 다시 받습니다.
  -> 앱 이름은 SmartScreen.app 그대로 두세요. 이름이 바뀌어 있으면 자동 업데이트가
     되지 않습니다 (띠에 그렇게 나옵니다).
  -> "앱 관리" 라는 말이 나오면 시스템 설정 > 개인정보 보호 및 보안 > 앱 관리 에서
     SmartScreen 을 허용한 뒤 [다시 시도] 를 누르세요.
  -> 업데이트 뒤에 블루투스 허용 창이 다시 뜨면 [허용] 을 누르세요.
